# 素材与软件来源

代码与制作流程由 GPT-6 Astra 在本地工具环境中实现。图像、三维渲染、音频合成没有调用额外的外部生成式 API 或付费云服务；第三方基础素材通过公开下载取得。

## 本项目制作内容

场景布局、虹桥、民居、瓦片、船体、衣饰、道具、植物、动画、镜头、转场、音乐旋律与配器均由项目脚本创建。水、风、脚步、木响及拨弦音色由本地信号处理生成。

模型细节与历史参考的关系见制作约定：本作属于三维艺术复原，原画未提供的空间、背面与尺度为合理推定。音乐属于当代国风管弦配器，不宣称复原北宋历史乐谱。

## 网页版本补充

- Three.js：MIT 许可，用于 WebGL 实时渲染、轨道控制、glTF 加载、水面、天空与后期。依赖源码及许可保存在 `node_modules/three/`，版本由 `package-lock.json` 固定；官方文档：https://threejs.org/docs/。
- Vite：MIT 许可，仅用于本地开发与静态打包。运行成品不需要访问 Vite 或 Three.js 的在线服务器。
- Draco：Apache 2.0 许可，用于本地压缩与解码几何。网页解码器随成品保存在 `public/draco/`。
- 眼球：MakeHuman 核心素材包 `eyes/low-poly/low-poly.obj` 与 `eyes/materials/brown_eye.png`，CC0；网格文件头含授权说明。应用于网页人物眼球与虹膜。
- 布料、灰泥细节与水面法线由本地数学程序生成，没有使用图像生成模型。
- 网页中原卷只作为资料对照；水流、树枝、人物、建筑、材质、摄影机及其运动在真实三维场景中计算。

- html-to-image 1.11.13：用于本地采集网页 DOM 界面层，MIT 许可。[官方源仓库](https://github.com/bubkoo/html-to-image)，许可随运行包存放在 `public/licenses/html-to-image-MIT.txt`。未使用在线图像生成服务。

Blender 是建模工具，未在 Git 仓库分发安装程序；Three.js 等 npm 依赖通过锁文件安装。`public/licenses/` 保留网页打包依赖的许可副本，公开发布时一并保留。

完整 OTF 字库和全分辨率长卷通过 `scripts/download_source_assets.py` 按需恢复；清单保留原始来源、固定字体版本和 SHA-256。网页运行使用的轻量字体与参考图已经包含在 `public/` 中。

本仓库尚未为原创代码和原创内容另行指定统一开源许可证。第三方资产依各自许可使用；上表不是对整个项目重新授权。
