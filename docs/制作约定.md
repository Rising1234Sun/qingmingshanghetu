# 入画·汴京

> 本文是早期离线影片阶段的历史方案，未完成离线全片；当前主成果、运行方法和 4K 展示规格以根目录 README 为准。

本工程使用张择端《清明上河图》作为视觉参考，由本地 Blender 几何模型、关键帧动画和 Python 音频处理完成。预算为零，不使用外部生成式 AI、云渲染、API 密钥或账号。

## 美术基准

- 参考卷为北京故宫藏张择端本，不混用清院本或仇英本。
- 重点为开放式木构虹桥、河运、临河市井；河中不添加桥墩，桥上不建廊屋。
- 青灰瓦、旧木、米色土墙、泥土路面、低饱和衣饰；商业招幌依据原画形式。
- 场景尺寸与原画没有交代的空间为三维艺术推定，不宣称考古级完整复原。
- 动画实际渲染 1440 帧，成片 1080×1920 / 24 fps / 60 秒；不以补帧或静帧重复代替动画。
- 近、中、远景按镜头可见程度分配几何细节；保留重新渲染与编辑所需文件。

## 制作顺序

1. 核对原画并搭建基础场景。
2. 检查虹桥正式样帧和 3 秒动画。
3. 完成六个镜头、人物、舟船、水波、布幌、柳枝和炊烟动画。
4. 编写原创 96 BPM 五声调式配乐，独立制作环境音。
5. 分镜头渲染 PNG，合成、检查成片与图片交付。
