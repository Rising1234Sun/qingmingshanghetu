# 网页验收记录

> 本文保存早期网页与 1080P 录像验收。当前 4K 与仓库发布的检查分别参见 [录制与视频制作](录制与视频制作.md) 和 [部署指南](部署指南.md)。

- 日期：2026-09-05。设备：本机 Apple M4、16 GB；验收使用 Codex 内置浏览器。
- 正式入口：`http://127.0.0.1:5186/`。静态产物在 `dist/`；通过一键启动器可以断网运行。
- 验证了桌面 1280×720 与手机 390×844 的实际布局，控件未横向溢出。
- 验证了五景切换、原卷对照、光照预设、模型线框、动画暂停、画质切换、取景比例及录制操作。
- 画面已实际检查：虹桥全景、临水近景、桥面人群、店铺近景和远景街区。
- 录像直接采集 WebGL 画布与 Web Audio 音轨。首轮完整测试得到 1080×1920、59.99 秒、约 23.96 fps、H.264/AAC；不是预设参数推断。
- 最终视频的元数据、解码检查、混音测量和 SHA-256 记录在 `网页实录验收.json`。
- 资源路径与长度校验在 `网页资源验收.json`，首次检查 24 个资源全部通过。
- 静态产物构建通过。Three.js 自身构建块大于 500 KB，Vite 提示体积提醒；这是打包提示，程序未依赖网络 CDN。

## 留给后续精修的客观边界

目前是以虹桥与汴河为核心的程序化三维艺术重建。建筑细节和远景实例采用不同精度；人物仍有程序动画的规律性；自由移动不是带碰撞约束的角色扮演游戏。历史尺度、原卷的每一栋房屋和每一位人物尚未逐一考证，不将当前效果宣称为实拍或完美复原。
