# 网页自动巡游镜头表

全长约 60 秒，镜头位置在 `src/tour.js` 中可编辑。录像的实际帧率以录制文件的元数据为准。

| 时间 | 镜头 | 展示重点 |
|---|---|---|
| 0–10 秒 | 从全景向虹桥靠近 | 河道、虹桥、两岸市井与城市层次 |
| 10–21 秒 | 贴近水面前进 | 舟船结构、竹篷、缆绳与倒影 |
| 21–33 秒 | 虹桥侧面抬升 | 木构拱架、桥面行人、桥下通航空间 |
| 33–43 秒 | 沿店铺横向移动 | 瓦片、棚布、摊主、顾客和器物 |
| 43–53 秒 | 从屋檐前方升起 | 街巷与两岸活动 |
| 53–60 秒 | 缓慢拉远 | 汴河及城市整体格局 |

录像源头是同一个实时三维场景。整理版保留原始 H.264 视频码流，仅整理音频响度与 MP4 索引，不使用生成式补帧或图像增强。
