# 模型、音乐与素材重建

运行网页只需 Node.js，仓库已经包含可用模型。本指南面向要修改几何、编曲和制作流程的人。全部命令默认在仓库根目录执行。

## 依赖与包含范围

| 目标 | 需要什么 |
|---|---|
| 网页运行和部署 | Node.js 24.x，`npm ci` |
| 修改相机、UI、实时动画 | `src/`，重新构建网页 |
| 重新生成三维模型 | Blender 4.5 LTS；本项目原环境为 4.5.13 |
| 编曲与视频剪辑 | Python 3.14、`requirements.txt`、本地 FFmpeg 二进制 |

仓库包含 `assets/characters/`、`assets/textures/`、字体许可和所有 `public/` 运行资产。完整中文字库约 23 MiB、原始长卷约 18 MiB、音乐采样 WAV 约 411 MiB，按需下载；所有生成的视频、Blender 安装程序和依赖目录都不提交到 Git。

`requirements.txt` 记录原环境精确版本。Blender 使用自身 Python，**不要给 Blender 的内置 Python 安装这份音视频依赖**。使用其他 Python 版本时先检查对应包的兼容性。

## 重建 Blender 工程和 GLB

重新建模或绘制视频字幕前，先恢复完整字体；只运行网页无需下载：

```sh
python3 scripts/download_source_assets.py --only font
python3 scripts/download_source_assets.py --check --only font
```

需要全分辨率原卷时执行 `python3 scripts/download_source_assets.py --only reference`。下载器依据 `assets/source-downloads.json` 核对大小与 SHA-256，保留已有但不一致的文件，不覆盖自己的修改。

从 [Blender 官方下载](https://www.blender.org/download/lts/) 安装 4.5 LTS。原项目采用 Apple Silicon 版本；Windows、Linux 选择相应平台。下列通用命令假设 `blender` 在 PATH 中：

```sh
blender -b --python-exit-code 1 --python scripts/build_web_scene.py
blender -b 汴京网页版.blend --python-exit-code 1 --python scripts/export_web.py
npm run build
npm run check -- --dist dist
npm start
```

macOS 默认安装到 Applications 时可以替换为：

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --python-exit-code 1 --python scripts/build_web_scene.py
/Applications/Blender.app/Contents/MacOS/Blender -b 汴京网页版.blend --python-exit-code 1 --python scripts/export_web.py
```

如果沿用原项目的便携安装，把可执行文件路径替换成 `tools/Blender.app/Contents/MacOS/Blender`。首次建模会生成 `汴京网页版.blend`；再次执行会更新它，手动精修前先另存自己的副本。

生成脚本已经包含原始贴图、基础人体和字体的读取逻辑，无需安装 MakeHuman 插件。`export_web.py` 在内存中进行简化与合批，输出 `public/models/bianjing.glb` 和 `manifest.json`；它不会把这些破坏可编辑性的导出步骤另存覆盖原 `.blend`。

不同 Blender 补丁版本或导出器实现可能使二进制校验值不同。目标是同一场景结构与可编辑流程，不保证跨平台逐字节一致。

## 常见修改位置

| 想修改 | 入口 |
|---|---|
| 建筑和摊位布局、人数 | `scripts/build_web_scene.py` |
| 屋瓦、桥、舟船、招牌形状 | `scripts/scenery.py`、`scripts/geometry.py` |
| 人物衣饰与关节 | `scripts/people.py` |
| 静态批次、动态标签、GLB 压缩 | `scripts/export_web.py` |
| 木纹、日光、水面、远景、实时运动 | `src/world.js` |
| 景点、六段巡游相机 | `src/tour.js` |
| 标签内容、控件行为 | `src/main.js`、`index.html` |
| 中文页面样式与手机布局 | `src/style.css` |

只改网页源码不需要重新建模；修改 Python 几何脚本后，需要重新建模、导出、构建。网页的轻量贴图已保存在 `public/textures/`，替换贴图时保持文件用途和颜色空间一致。

## 安装音视频依赖

```sh
python3.14 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Windows 对应的解释器路径为 `.venv\Scripts\python.exe`。FFmpeg 由 `imageio-ffmpeg` 包提供，无需使用系统中可能缺失依赖的另一版本。

## 恢复采样并重新编曲

`assets/audio/vsco-downloads.json` 固定了上游提交、文件路径、大小和 SHA-256。下载器仅使用 Python 标准库，从 VSCO 2 CE 官方源码仓库获取选定 WAV，无需账号和 API Key：

```sh
python3 scripts/download_audio_samples.py --check
python3 scripts/download_audio_samples.py
python3 scripts/download_audio_samples.py --check
.venv/bin/python scripts/compose.py
.venv/bin/python scripts/compose_demo.py
```

首次 `--check` 会报告缺失资产并以非零状态退出，这是预期行为。下载时已有且校验一致的文件自动跳过；只想检查一个采样的下载过程，可先用 `--limit 1`。

60 秒音频写入 `output/audio/`，两分钟音频写入 `output/audio/两分钟功能演示/`，同时保留声部、环境音、混音和 MIDI。终端输出会记录混音测量。网页当前使用的 `public/audio/bianjing.mp3` 已包含在仓库，重新编曲不会自动替换网页 MP3；确认试听后自行转换并替换，再构建。

## 参考资料与历史脚本

原卷参考位于 `references/`，网页对照图在 `public/reference/`，具体来源见 [素材来源](素材来源.md)。基础面部网格与纹理属于 MakeHuman 核心资产，衣饰、道具和场景由本项目脚本组合生成。

`prepare_assets.py` 是早期从本地压缩包和部分 Git 检出整理素材的脚本，它假设 `vendor/` 已存在。**新克隆不需要运行它**：建模素材已随仓库提供，音频使用上述独立下载器恢复。

`build_scene.py`、`pipeline.py`、`render.py`、`assemble.py`、`revise_camera.py` 为离线影片探索保留。它们引用的旧工程和帧序列不属于当前网页快速启动流程。旧版报告中的 1080P/60 秒规格只是历史记录；当前展示主文件规格见 [4K 录制与剪辑](录制与视频制作.md)。

## 重建后的验收

先检查虹桥全景与茶肆近景，确认门窗、桥板、人物和道具没有意外缺失。依次打开五景、标签、原卷、地图和画面设置。查看模型清单和真实浏览器读数，再试一次 PNG 导出。只有需要修改录制功能时才重新长时间录制，避免把重复拍摄当成构建必需步骤。
